# Odhyay

This is Odhyay - an online question bank dedicated to the students of HSC and public university admission candidates of Bangladesh.

## Features

Odhyay gives you:

- A well organized question bank that has questions from every HSC board, every university and every year.
- Questions are searchable through filters by exam, subject, topic and year.
- Students can quiz themselves on specific chapters/topics for practice.
- Students can track their preparation progress and consistency.
- There are options to take exams chapter wise or Full syllabus and compare results with other participants using the app.
- There is an admin panel from where questions can be added, removed or edited.
- Students can report problems on questions if there is a problem with the question. Based on the reports, the admin can edit the question if there is any problem.

## Setting Up the Project

To run the project locally, you will need: git, npm and a browser.


1. First clone the github repo using the following command

```
git clone https://github.com/imran-saleh110/odhyay.git
```

2. `cd` into the project and run the following commands:

```bash
cd odhyay

npm install
npm run build && npm run dev
```
